## 1. Tóm tắt

**Tổng 87 FR Must: 77 Đủ, 10 chưa đủ** (Thiếu FE 3, Thiếu BE 3, Thiếu test 1, Lệch SRS 3). Đối chiếu ngày 2026-10-21 trên nhánh `docs/134-fr-must-matrix`, commit develop `7383885`. Cả 6 phần "Không cắt" ở SRS 12.6 đều **chưa đủ 100%** (mục 3).

Cách đọc cột:
- **Module (người)**: README ghi người sở hữu theo vai (BE1–BE4), không ghi tên người. Module lấy theo package chứa code thực tế.
- **Test**: `Class#phương_thức`, đã mở file test để xác nhận phương thức tồn tại. Rút gọn khi nhiều.
- **Màn hình FE**: route trong `frontend/src/app/router.tsx` · service gọi API trong `frontend/src/services/`. "Chưa có FE" = route là `AdminUnderDevelopment` hoặc đọc dữ liệu từ store cũ. "—" = FR do hệ thống/nền, không có màn hình riêng.
- **Docs API**: ✓ = `docs/api/<file>.md` có mô tả endpoint.

## 3. Không cắt (SRS 12.6)

SRS 12.6 ghi "Không cắt: Đăng bài + phí + kiểm duyệt tầng 1 và 3; giao dịch tới Completed; nạp Credit; khiếu nại; báo cáo tài chính". Tôi chia thành 6 phần: (1) đăng bài + phí, (2) kiểm duyệt tầng 1 và 3, (3) giao dịch tới Completed, (4) nạp Credit, (5) khiếu nại, (6) báo cáo tài chính. **Cả 6 phần đều chưa đủ 100%.**

| # | Phần | FR thuộc phần | FR chưa Đủ | Kết luận |
